# Sslow...App

Aplicación web interactiva inspirada en el movimiento *slow life* para promover bienestar mental, hábitos conscientes y una vida más calmada.

## Qué incluye

- Inicio de sesión básico para personalizar la experiencia.
- Página principal con frase motivacional diaria.
- Clúster de 4 servicios:
  - Hábitos conscientes.
  - Tareas slow (hoy y mañana).
  - Slow recipes.
  - Diario emocional.
- Diario emocional con guardado por fecha y visualización de evolución.
- Bloc de notas tipo diario.
- Interfaz aesthetic con tonos tierra, beige y verdes, y navegación inferior con iconos de línea.

## Ejecutar localmente

Como es una app estática, puedes abrir `index.html` directamente o levantar un servidor local:

```bash
python3 -m http.server 8000
```

Luego abre `http://localhost:8000`.
